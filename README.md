# CS-300-Portfolio

## About This Portfolio
Welcome to my CS-300 portfolio repository! This collection showcases the core projects and analyses I completed throughout this course, focusing on efficient data structures, algorithmic problem-solving, and clean C++ implementation.

---

## Project Reflections

### 1. What was the problem you were solving in the projects for this course?
In these projects, the main challenge was figuring out how to efficiently store, organize, and retrieve data using the right data structures and algorithms in C++. Project One required breaking down and evaluating the memory usage and execution run-times of different data structures to see which one fit best. Project Two focused on building a working C++ program that loads course data and sorts the Computer Science catalog in alphanumeric order.

### 2. How did you approach the problem? Consider why data structures are important to understand.
My approach started with analyzing performance constraints and understanding Big-O notation. Understanding data structures is crucial because choosing the correct structure—whether it's a vector, hash table, or binary search tree—completely changes how scalable, fast, and memory-efficient your program will be when handling large datasets.

### 3. How did you overcome any roadblocks you encountered while going through the activities or project?
Whenever I hit roadblocks, like sorting logic errors or pointer bugs, I tackled them by breaking the code down into smaller, testable chunks. Using debugging tools to step through variable states and cross-referencing C++ documentation helped me track down issues and fix my algorithmic flow.

### 4. How has your work on this project expanded your approach to designing software and developing programs?
Working on these projects completely shifted my mindset from just writing code that "works" to architecting software that is resource-conscious and robust. I now focus much more on modular design and weighing performance trade-offs before writing a single line of implementation code.

### 5. How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
This coursework really emphasized clean coding practices, meaningful variable naming, and clear comments. Because of that, my code is much easier to read and maintain now. Keeping my code modular also ensures that if requirements change later, the individual components are simple to extend or refactor.
